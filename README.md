# 🎓 スマート授業プリント＆AI暗記ノート (Smart Lecture Note)

スマホ（iPhone / Android）やタブレット・PCで、配布されたPDFプリントに直接**横書き・縦書き**で文字を打ち込んだり、蛍光マーカーやペンで書き込みができるWebアプリ（PWA）です。  
暗記用の**デジタル赤シート機能**や、授業メモをもとにChatGPT・Geminiにテスト予想問題を作らせる**AI勉強プロンプト自動生成機能**を搭載しています。

---

## ✨ 主な機能

1. **📚 教科別フォルダ管理・白紙ノート作成**
   - 国語、数学、英語、理科、社会などの教科フォルダを作成・色分け管理。
   - 配布されたPDFプリントの取り込みだけでなく、途中に「縦罫線（国語用）」「5mm方眼（数学・理科用）」「横罫線」「無地」の白紙ノートページをいつでも挿入可能。

2. **✍️ 横書き・縦書きテキスト入力（ハイブリッド）**
   - タップした位置にテキストボックスを配置し、スマホキーボードで文字入力。
   - テキストボックスごとにワンタップで「横書き ⇔ 縦書き」を自由に切り替え可能（国語の行間メモにも最適）。
   - 文字サイズ、文字色の変更と前回設定の自動記憶。

3. **🖍️ マーカー・ペン・直線モード・スタンプ**
   - 半透明の蛍光マーカー（黄・ピンク・青・暗記緑）。
   - 定規いらずで真っ直ぐ引ける「直線モード」。
   - 丸つけや矢印、手書き数式用の細字ペン。
   - `★重要` `？不明` `○` `×` `✓済` スタンプをワンタップ配置。
   - 消しゴムツール ＆ やり直し（Undo / Redo）対応。

4. **🈴 デジタル赤シート（暗記モード）**
   - 赤・オレンジの文字や暗記マーカーをワンタップで黒塗り・マスク。
   - タップすると答えがパッとめくれるので、通学中などにスマホ1台で暗記テストが可能。

5. **🤖 AIテスト勉強連携（ワンタップコピー）**
   - 元のPDF本文 ＋ 授業中に書き込んだメモ（特に「赤字」「★重要」「？不明」）を自動整理。
   - 「赤字と★から一問一答・予想問題を作らせる」「？不明箇所をわかりやすく解説させる」「要点まとめノートを作らせる」プロンプトを一瞬で生成・コピー。

6. **🔍 全プリント横断キーワード検索 ＆ 重要ページまとめ**
   - 全プリントの本文＋自分のメモからキーワードを一発検索して該当ページにジャンプ。
   - 全プリントから「★重要」「？不明」スタンプが押されたページだけを一覧抽出。

7. **💾 日本語フォント統合PDF出力**
   - 書き込んだ文字・マーカー・スタンプ・挿入したノートページをすべて統合したPDFファイルとして保存・共有。

## 🚀 使い方

### ローカル（PC＋同じWi-Fiのスマホ）で動かす場合

1. リポジトリをクローンまたはダウンロード
2. サーバーを起動：
   ```bash
   python server.py
   ```
3. 表示されたURLにアクセス：
   - PC: `http://localhost:8080`
   - スマホ: `http://<ローカルIP>:8080`（PCと同じWi-Fiに接続）

### GitHub Pagesで公開する場合
本リポジトリの設定（`Settings` > `Pages`）で `Deploy from a branch` を選び、`main` ブランチを指定するだけで、ネット経由でどこからでもスマホからアクセスできるようになります。

## 🛠️ 技術スタック
- **Frontend**: Vanilla JavaScript (ES Modules), HTML5, CSS3 (Mobile First / Responsive)
- **PDF Rendering**: Mozilla PDF.js (`pdfjs-dist`)
- **PDF Manipulation & Font Embedding**: `pdf-lib` + `@pdf-lib/fontkit` + Noto Sans CJK JP
- **Storage**: IndexedDB（完全ローカル完結・通信不要・自動一時保存）
- **PWA**: Web App Manifest (`manifest.json`)
